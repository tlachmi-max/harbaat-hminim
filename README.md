# אישור איסוף ארבעת המינים — הוראות התקנה

המערכת מורכבת משני חלקים:

1. **Code.gs** — סקריפט שמתחבר לגיליון ההזמנות שלכם ומאפשר בדיקה ועדכון.
2. **index.html** — דף הנחיתה שהמשתתפים יפתחו כדי לאשר שאספו.

הכול פועל מהאייפון, בלי מחשב או טרמינל.

---

## שלב 1 — התקנת הסקריפט על הגיליון

1. פתחו את גיליון ההזמנות ב-Safari:
   `https://docs.google.com/spreadsheets/d/1fr5geyzdLn8jKY43QUlfS6cx91QRr3PuIYUTKFjwf7Y/edit`
2. תפריט ה-☰ למעלה ← **שלוחות (Extensions)** ← **Apps Script**.
3. מחקו את הקוד לדוגמה שכבר שם, והדביקו את כל תוכן הקובץ `Code.gs`.
4. שמרו (סמל הדיסקט).
5. **פרוס (Deploy)** ← **פריסה חדשה (New deployment)**.
6. ליד "בחר סוג" (גלגל שיניים) בחרו **אפליקציית אינטרנט (Web app)**.
7. הגדרות:
   - מבצע הפעולה בשם (Execute as): **אני (Me)**
   - מי יכול לגשת (Who has access): **כל אחד (Anyone)**
8. לחצו **פרוס (Deploy)**. Google יבקש הרשאה — אשרו (אם מופיעה אזהרה "האפליקציה לא מאומתת", לחצו "מתקדם" ואז "המשך").
9. תקבלו כתובת URL שמסתיימת ב-`/exec`. **העתיקו אותה.**

> אם תעדכנו את הקוד בעתיד, צריך לבחור **פריסה חדשה** שוב — עריכה בלבד לא מפעילה את השינוי.

---

## שלב 2 — חיבור הדף לסקריפט

1. פתחו את `index.html`.
2. חפשו את השורה:
   ```
   const WEBAPP_URL = 'PASTE_YOUR_APPS_SCRIPT_URL_HERE';
   ```
3. הדביקו במקומה את כתובת ה-`/exec` שהעתקתם בשלב הקודם.

---

## שלב 3 — פרסום ב-GitHub Pages

1. העלו את `index.html` לריפו של GitHub Pages שלכם (כמו בפרויקטים הקודמים).
2. הדף יהיה זמין בכתובת ה-Pages הרגילה שלכם.
3. שתפו את הקישור בקבוצות הוואטסאפ של הקיבוץ.

---

## איך זה עובד

- הגיליון חייב להכיל עמודות בשם **"שם מלא"** ו-**"טלפון"** (כפי שכבר קיים מהטופס).
- בהרצה הראשונה הסקריפט מוסיף לבד שתי עמודות: **"אישור איסוף"** ו-**"זמן אישור"**.
- משתתף מזין טלפון ← הדף בודק מול הגיליון ← אם נמצא, מציג את השם ומבקש אישור ← לחיצה על "כן, אספתי" מסמנת "כן" + שעה בגיליון.
- אם אותו טלפון הופיע כמה פעמים (למשל כמה הזמנות), כל השורות המתאימות מסומנות יחד.
